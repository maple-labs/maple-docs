# Pools

A Pool is the ERC-4626 vault that Lenders deposit into. Its Pool Manager holds the Pool's settings, decides which strategies the Pool funds and how much each may hold, and aggregates the accounting that prices Pool shares. The queue-based Withdrawal Manager handles exits. These pages cover each contract and the accounting that ties them together.
