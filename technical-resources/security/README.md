# Security

How Maple keeps the protocol safe. Every release is audited before it ships, a public bug bounty runs continuously, and on-chain monitoring checks the protocol's invariants every block. This section also records what the contracts assume about trusted actors, the behaviours Maple controls through operating procedure rather than code, every externally callable function, and the pause levers available in an incident.
